Mini Checkout Application Overview

Component Hierarchy, State Management & Fixed-Price Product Catalogue

01 / 05
1

Product Catalogue Component

Centrally defined in JavaScript with immutable pricing. Features Wireless Headphones (P001 @ ₹1,499.00) and Smart Watch (P002 @ ₹2,499.00). User input tampering of pricing is strictly prevented.

Immutable Catalogue Engine
2

Shopping Cart & Floor Bounds

Reactive state updates on add, remove, and quantity mutations. Enforces a strict minimum quantity floor of 1, preventing negative or zero cart items.

Stateful Cart Management
3

Financial Calculation Engine

All line subtotals and grand totals are calculated in integer paise (149900 + 249900 paise) internally to eliminate floating-point currency drift.

Integer Paise Math (Zero Drift)
4

Accessible Form Validation

Customer name requires whitespace trimming before validation. Associates field errors with aria-describedby and aria-invalid="true", preserving user input upon rejection.

ARIA-Compliant Validation
5

Synchronous Concurrency Lock

Immediate synchronous boolean lock flag prevents rapid double-clicks (< 10ms) from creating multiple orders or duplicate reference numbers.

Race-Condition Immunity
6

Simulated Order Confirmation

Renders a single confirmation card containing customer name, formatted total, and a unique reference matching ORD-2026-XXXXXX, permanently disabling checkout controls.

Simulated Post-Checkout State
